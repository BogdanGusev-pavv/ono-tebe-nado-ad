# Проект «Оно тебе надо»

Учебный проект — сайт аукциона необычных вещей, в которые когда-то никто не верил.

## О проекте

Сайт представляет собой страницу аукциона, на которой размещены:
- Шапка сайта с навигацией и контактной информацией.
- Обложка с названием проекта и кнопкой перехода к лотам.
- Раздел с тремя карточками аукционных лотов.
- Раздел с информацией об аукционе.
- Подвал с контактами, навигацией и ссылками на социальные сети.

## Технологии

- HTML5
- CSS3
- Flexbox
- Grid Layout

## Структура проекта

- `index.html` — HTML-разметка страницы.
- `styles/` — таблицы стилей.
- `fonts/` — файлы шрифтов.
- `images/` — изображения и логотипы проекта.

## Запуск проекта

Откройте файл `index.html` в браузере.
